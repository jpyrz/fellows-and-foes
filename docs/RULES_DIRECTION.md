# Fellows & Foes Rules Direction

## D&D-Style Stats

The alpha currently uses four compressed stats: Might, Finesse, Mind, and Spirit. That is easy to read, but it feels generic compared with the D&D language we want the game to evoke.

For the next rules pass, consider moving to six ability-style stats:

- Strength: force, heavy weapons, breaking, carrying.
- Dexterity: precision, defense, stealth, initiative.
- Constitution: health, endurance, poison, exhaustion.
- Intelligence: lore, investigation, arcane logic.
- Wisdom: perception, intuition, survival, resolve.
- Charisma: persuasion, command, deception, presence.

Character creation should probably use a small point-buy or standard array instead of the current `3/2/1/1`. A clean alpha-friendly option would be `15/14/13/12/10/8`, then derive modifiers from those values.

## Exploration Checks

D&D exploration is not usually turn-based unless time pressure matters. The important thing is that the acting character matters, the risk is clear, and failure changes the situation.

For Fellows & Foes, story checks should follow this structure:

1. Show the selected actor, stat, DC, chance, and stakes before rolling.
2. Surface the best-suited party member without forcing the choice.
3. Make failed checks do one of four authored things: close that lead, cost health/resources, reveal a worse path, or require advantage before retrying.
4. Avoid permanent dead ends. Failure can hurt, redirect, or narrow options, but it should not block campaign completion.
5. Use consequences that persist into battle when possible, such as lost health, missing item rewards, enemy weaknesses not revealed, or safer paths staying locked.

The goal is not to punish every click. The goal is to make the player ask, “Who should do this, and what happens if this goes badly?”
